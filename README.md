# Tinig — Free AI Text to Speech

Free text-to-speech website that runs entirely in the browser. No sign-up, no API token.

- **AI voices** (28 English voices, US & UK) powered by the open-source [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) model (Apache-2.0) via [kokoro-js](https://www.npmjs.com/package/kokoro-js). Generate and **download WAV** audio.
- **Device voices** using the browser's built-in speech voices (many languages, play only).

Live site: https://ajcajandab-png.github.io/tinig-tts/
